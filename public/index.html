askBack

askBack answers private WhatsApp chats when that is on. In groups you turn on, it answers only when tagged. It reads the chat, files, images, and documents. If it does not understand, it stays quiet.

Knowledge

Upload one or more files: WhatsApp chat exports (.txt or zip with media), PDFs, images, Word/Excel/PowerPoint, or audio. Give a shared name (e.g. Group photos). Each selected file is added to Knowledge.

    Send to a group

    Type a message, pick text or a voice note, then askBack will post it in the WhatsApp group you pick. This voice is also used when askBack replies to a voice note.
