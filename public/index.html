askBack

askBack answers private WhatsApp chats when that is on. In groups you turn on, it answers only when tagged. It reads the chat, files, images, and documents. If it does not understand, it stays quiet.

Knowledge

Upload one or more files: WhatsApp chat exports (.txt or zip with media), PDFs, images, Word/Excel/PowerPoint, or audio. Stickers have their own section below.

    Stickers

    Loaded from the stickers/ folder in the project. Drop .webp / .png files there (or upload below). Name them clearly, e.g. friend.png, thanks.webp.
